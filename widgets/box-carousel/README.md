# Box Orbit Carousel

An isolated React 18/TypeScript widget adapted from the supplied **21st.dev dish-orbit-carousel**. The main website remains plain HTML/CSS/JavaScript. No Tailwind, shadcn, icon library or stock imagery is used.

## Rebuild

From this directory:

```sh
npm install
npm run build
```

Commit both the source changes and the regenerated `/assets/js/box-carousel.js` and `/lebanon/index.html`. Deploy the repository root to Netlify as static files; no hosted build step is needed. The build type-checks, emits one minified IIFE with injected CSS and no source map, and regenerates the static fallback from the shared data/config.

The only direct packages are react, react-dom, gsap, vite, @vitejs/plugin-react and typescript. Local React hook/JSX declarations avoid an additional @types dependency; data, helper functions and component props are TypeScript-checked. The package lock pins the build's dependency graph.

## Data and display setting

Edit `/box-items.js`, which exports `window.BOX_ITEMS` in the same browser-global style as the site's other data files. Example objects contain empty maker fields and describe generic product types only. The existing PNG filenames are reserved paths, not supplied or claimed inventory. Examples always use flat, transparent SVG illustrations in the allowed accents, regardless of whether a PNG exists.

Set `SITE_CONFIG.BOX_ITEMS_MODE` in `/config.js`:

- `examples`: only `example: true`; maker details and maker links are always suppressed.
- `real`: only `example: false` with a nonempty maker name and a successfully decoded local asset. At least three must qualify. The static build also checks that the local file exists.
- `hidden`: no visible section and no page links into it. Unknown values also fail closed.

**Rebuild after changing data or this setting.** JavaScript-enabled browsers evaluate the current config/data and validate real images. A JavaScript-disabled browser cannot execute a JS config file: its fallback is the HTML snapshot generated by the last local build. This is why the build regenerates the six-item vertical list (or the appropriate real/hidden snapshot). If the bundle or data script fails, the generated fallback remains usable. No test makers or product photos are included.

The root `MODE` is unchanged and still chooses the widget CTA: waitlist → `#waitlist`, live → `#pricing`. Existing `#inside` links resolve to the new `#box-items` section through an alias. `#makers` aliases the existing maker section; its copy and layout are unchanged.

## Loading and animation

A small inline page loader renders the fallback from the shared data, then requests the committed bundle only within 300px of the section using IntersectionObserver. The fallback is hidden only after React has painted the widget. The component retains the supplied GSAP orbit swing, `SWING = 50`, title wipes, card transition, arc path/math and timing. Layout, text sizes, data fields and controls are adapted to the site. It does not advance on page scroll by default.

`pinScroll` defaults to false. The default production build excludes the ScrollTrigger module entirely, along with its wheel listener and extra scroll height. To build optional original pinning support, use `BOX_PIN_SCROLL=true npm run build` and opt into `pinScroll` at the mount. The build-time opt-in reconciles the single-file requirement with keeping the plugin out of the default file. Pinning remains disabled on mobile and with reduced motion. The deployed mount deliberately passes false.

Reduced motion switches instantly, including the thumbnail strip, and reacts to preference changes. Controls support arrows, pager buttons, thumbnails, keyboard, detail tabs and product-image swipe. Inactive content is aria-hidden/inert and excluded from keyboard focus.

## Typography and source credit

The original embedded Outfit font (SIL Open Font License 1.1) is omitted; `fontSrc={null}` is passed. DM Sans weights 200 and 800 provide the title's two weights. Google's stylesheet endpoint was unavailable in the build environment, so these Google Fonts files are self-hosted from the Fontsource DM Sans distribution, with the existing DM Sans OFL license in `/assets/dm-sans-LICENSE.txt`. No Fontsource package is an application dependency. No third-party font request is needed at runtime.

The component's own commercial-use license still requires confirmation before launch; the font license does not establish the component license. This is recorded in TODO.md.

## Verification

See the box-carousel follow-up in `/QA.md`. Real-item fixtures were injected only by local browser tests and were never saved into the production data. File-size totals are measured from the generated JS, not an estimate; no source map is shipped.

Final production artifact: **231,985 bytes minified**, **79,613 bytes gzip** (approximately 232 kB / 79.6 kB). The separate shared data file and self-hosted font files are not part of that JS byte count.
